# Watchfloor Live

내 PC에서 돌아가는 실시간 OSINT 지구본이에요. 평소에는 지구본이 천천히 돌다가, 큰 지진이나 긴급지진속보가 들어오면 그 위치로 날아가 확대하고 P파·S파, 도시별 도달 시간, 주변 원전, 주변 항공기, 현지 카메라를 띄워요.

## 1. 준비물

- **Node.js 18 이상** (https://nodejs.org 에서 LTS 버전 설치)
- 인터넷 연결

## 2. 실행

| 운영체제 | 방법 |
|---|---|
| Windows | `start-windows.bat` 더블클릭 |
| macOS | `start.command` 더블클릭. 막히면 터미널에서 `bash start.command` |
| 공통 (터미널) | 이 폴더에서 `npm install` 한 번, 그다음 `npm start` |

브라우저가 자동으로 열려요. 안 열리면 **http://localhost:3117** 로 들어가세요.
끄려면 검은 창에서 `Ctrl + C`.

인터넷 없이 화면만 보고 싶으면 `demo-windows.bat` 또는 `npm run demo` (저장된 지진 기록을 재생해요).

> `public/index.html`을 직접 열면 동작하지 않아요. 꼭 위 방법으로 서버를 켜고 주소로 들어가세요.

## 3. 실시간으로 들어오는 것

| 데이터 | 출처 | 갱신 | 키 |
|---|---|---|---|
| 전 세계 규모 4.5+ 지진 | USGS | 1분 | 필요 없음 |
| 일본 지진 정보 (관측 진도 포함) | 일본 기상청 → P2P지진정보 API | 15초 | 필요 없음 |
| 일본 긴급지진속보 (경보) | 같음 | 15초 | 필요 없음 |
| 일본 쓰나미 경보·주의보 | 같음 | 15초 | 필요 없음 |
| 사고 지점 주변 실시간 항공기 | airplanes.live → adsb.fi → adsb.lol (자동 전환) | 지진 확대할 때 | 필요 없음 |
| 현지 웹캠 영상 | Windy Webcams / 내가 등록한 유튜브 라이브 | 지진 확대할 때 | Windy는 무료 키 |
| AI 상황 분석 | Claude (Anthropic) | 버튼 누를 때 | 유료 API 키 |

상단 오른쪽 점이 각 출처 상태예요. 초록 = 정상, 주황 = 대기/오프라인 기록, 빨강 = 연결 실패, 회색 = 꺼짐.

## 4. 선택 기능 켜기 (.env)

`.env.example`을 복사해서 이름을 `.env`로 바꾸고 필요한 키만 넣은 뒤 다시 실행하세요.

- `WINDY_API_KEY` : https://api.windy.com/keys 에서 Webcams API 키 발급(무료 등급 있음). 넣으면 지진 근처 웹캠이 팝업 안에서 바로 재생돼요.
- `ANTHROPIC_API_KEY` : https://console.anthropic.com 에서 발급. 넣으면 "상황 브리핑" 탭의 **Claude 분석 요청** 버튼이 켜져요. 누를 때마다 요금이 나가요 (30초에 1회 제한).

### 유튜브 라이브 카메라 등록 (cams.json)

자주 보는 라이브캠이 있으면 `cams.json`에 넣어 두세요. 근처(기본 800km)에서 지진이 나면 팝업에서 자동 재생돼요.

```json
{ "name": "도쿄 시부야", "lat": 35.659, "lng": 139.700, "youtube": "영상ID", "radiusKm": 800 }
```

`youtube`에는 주소 `watch?v=` 뒤의 ID만 넣어요. 라이브 ID는 채널 사정으로 바뀔 수 있어요.

## 5. 조작

| 키 | 동작 |
|---|---|
| Space | 새 경보가 와도 자동으로 날아가지 않게 끄기/켜기 |
| N | 최근 주요 지진 순서대로 이동 |
| E | 긴급지진속보 테스트 (가짜 속보로 연출 확인) |
| J | J-Alert 미사일 데모 |
| 1–6 | 레이어: 지진, 원전, 해상 요충지, 주요 항로, 실시간 항공기, 낮/밤 |
| Esc | 정보 창 닫기 |

지구본의 지진 점, 피드 항목, 하단 타임라인 막대를 누르면 그 지진으로 이동해요.

## 6. 알아 두세요

- 진도 추정, 지진파 도달 시간, 쓰나미 도달 시간은 공식 값이 아니라 공식을 이용한 대략치예요. 실제 대피 판단은 반드시 기상청·재난문자 같은 공식 경보를 따르세요.
- 긴급지진속보는 P2P지진정보가 기상청 발표를 중계한 것이라 몇 초 늦을 수 있어요.
- 항공기 데이터는 airplanes.live·adsb.fi·adsb.lol 자원봉사 수신망 기준이라 지역에 따라 비어 있을 수 있어요.
- PC에서 실행하면 서버는 내 PC(127.0.0.1)에서만 열려요. 다른 기기에서도 보려면 아래 "사이트로 올리기"를 쓰세요.

## 7. 문제 해결

- **"포트 3117을 이미 쓰고 있어요"** : 이미 켜져 있는 창이 있는지 확인하거나 `.env`에서 `PORT=3118`처럼 바꾸세요.
- **화면에 지진이 안 나와요** : 상단 USGS 점이 빨간색이면 인터넷 연결이나 방화벽을 확인하세요. 연결이 안 되면 저장된 기록으로 대신 보여줘요.
- **AI 버튼이 회색이에요** : `.env`에 `ANTHROPIC_API_KEY`가 있는지, 서버를 다시 켰는지 확인하세요.

## 8. 사이트로 올리기 (Render 무료)

1. 이 폴더를 GitHub 저장소에 올려요.
2. https://render.com 에 GitHub로 가입하고 **New → Blueprint**에서 그 저장소를 골라요. `render.yaml`을 읽어서 알아서 설정돼요.
3. 키를 묻는 칸이 나오면 필요한 것만 넣어요. 비워 둬도 돼요.
   - `WINDY_API_KEY` : 웹캠 영상
   - `ANTHROPIC_API_KEY` + `ADMIN_PASSWORD` : Claude 분석. 사이트에서는 **비밀번호를 같이 넣어야만** 켜져요 (남이 눌러 요금이 나가는 걸 막으려고요).
4. 배포가 끝나면 `https://watchfloor-xxxx.onrender.com` 주소가 생겨요.

무료 요금제는 15분쯤 아무도 안 들어오면 잠들어서, 다음에 열 때 30초~1분 걸려요. 사이트 모드에서는 "속보 테스트"가 내 화면에서만 재생되고 다른 사람 화면에는 안 떠요.

## 폴더 구성

```
server.js          실시간 데이터 수집 + 화면 제공
public/            화면 (index.html, 지도 데이터, globe.gl)
data/snapshot.json 오프라인/데모용 지진 기록
cams.json          내가 등록하는 유튜브 라이브캠
.env.example       선택 기능 키 예시
render.yaml        Render 사이트 배포 설정
```

globe.gl (MIT 라이선스) 을 `public/vendor/`에 포함하고 있어요.
