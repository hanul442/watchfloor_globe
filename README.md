# Watchfloor Live

실시간 OSINT 지구본이에요. 지진, 긴급지진속보, 쓰나미, 뉴스 기사, NASA 자연재해 같은 자료를 모두 **사건** 단위로 묶어서 보여 줘요. 평소에는 지구본이 천천히 돌다가, 큰 사건이 들어오면 그 위치로 날아가 확대하고 사건 카드를 띄워요. 사건 카드에는 묶인 자료(신호) 목록, 주변 사건·원전·요충지와의 연결 그래프, 현지 카메라, Claude 분석 버튼이 있어요. 지진이면 P파·S파와 도시별 도달 시간도 함께 보여 줘요.

## 사건 중심 구조

- 들어오는 자료 하나하나를 **신호**라고 불러요. USGS 지진, 기상청 지진·속보·쓰나미, 뉴스 기사, NASA 재해 정보가 모두 신호예요.
- 서버가 같은 일을 다룬 신호를 하나의 **사건**으로 묶어요.
  - USGS와 기상청의 같은 지진: 10분, 150km 안이면 하나로 묶어요.
  - 같은 지역 기사: 48시간 안, 도시는 350km, 나라는 900km 안이면 하나로 묶어요.
  - 지진 기사는 근처 지진 사건에 붙고, 재난 기사는 근처 NASA 재해 사건에 붙어요.
- 사건 유형은 지진, 쓰나미, 분쟁, 재난, 사고, 주요 뉴스예요. 기사는 제목 단어로 유형을 나눠요.
- 심각도는 1~5예요. 지진은 규모와 진도로, 기사는 속보 여부와 보도한 언론사 수로 정해요.
- 신뢰도는 공식 자료가 있으면 높음이고, 기사만 있으면 출처 수에 따라 올라가요.
- 왼쪽 피드, 지구본 점, 아래 타임라인, 검색이 모두 사건 단위예요.

## 1. 준비물

- **Node.js 18 이상** (https://nodejs.org 에서 LTS 버전 설치)
- 인터넷 연결

## 2. 실행

| 운영체제 | 방법 |
|---|---|
| Windows | `start-windows.bat` 더블클릭 |
| macOS | `start.command` 더블클릭. 막히면 터미널에서 `bash start.command` |
| 공통 (터미널) | 이 폴더에서 `npm install` 한 번, 그다음 `npm start` |

브라우저가 자동으로 열려요. 안 열리면 **http://localhost:3117** 로 들어가세요.
끄려면 검은 창에서 `Ctrl + C`.

인터넷 없이 화면만 보고 싶으면 `demo-windows.bat` 또는 `npm run demo` (저장된 지진 기록을 재생해요).

> `public/index.html`을 직접 열면 동작하지 않아요. 꼭 위 방법으로 서버를 켜고 주소로 들어가세요.

## 3. 실시간으로 들어오는 것

| 데이터 | 출처 | 갱신 | 키 |
|---|---|---|---|
| 전 세계 규모 4.5+ 지진 | USGS | 1분 | 필요 없음 |
| 일본 지진 정보 (관측 진도 포함) | 일본 기상청 → P2P지진정보 API | 15초 | 필요 없음 |
| 일본 긴급지진속보 (경보) | 같음 | 15초 | 필요 없음 |
| 일본 쓰나미 경보·주의보 | 같음 | 15초 | 필요 없음 |
| 사고 지점 주변 실시간 항공기 | airplanes.live → adsb.fi → adsb.lol (자동 전환) | 지진 확대할 때 | 필요 없음 |
| 세계 뉴스 (위치 자동 추정) | BBC · 알자지라 · NPR · 연합뉴스 · 구글뉴스 속보 RSS | 3분 | 필요 없음 |
| 자연재해 (산불·태풍·화산·홍수) | NASA EONET | 30분 | 필요 없음 |
| 위성 위치 (우주정거장·밝은 위성 약 200개) | CelesTrak 궤도 요소 → 브라우저에서 계산 | 6시간 (위치는 3초) | 필요 없음 |
| 선박 위치 (한·일 근해와 주요 해협) | aisstream.io | 실시간 | 무료 키 |
| 현지 웹캠 영상 | Windy Webcams / 내가 등록한 유튜브 라이브 | 지진 확대할 때 | Windy는 무료 키 |
| 관련 뉴스 영상 | 유튜브 검색 (최근 1주일) | 뉴스 사건 열 때 | 필요 없음 (키 넣으면 공식 API) |
| AI 상황 분석 | Claude (Anthropic) | 버튼 누를 때 | 유료 API 키 |

왼쪽 패널 아래쪽 점이 각 출처 상태예요. 초록 = 정상, 주황 = 대기/오프라인 기록, 빨강 = 연결 실패, 회색 = 꺼짐.

## 4. 선택 기능 켜기 (.env)

`.env.example`을 복사해서 이름을 `.env`로 바꾸고 필요한 키만 넣은 뒤 다시 실행하세요.

- `WINDY_API_KEY` : https://api.windy.com/keys 에서 Webcams API 키 발급(무료 등급 있음). 넣으면 지진 근처 웹캠이 팝업 안에서 바로 재생돼요.
- `YOUTUBE_API_KEY` : 없어도 돼요. 비워 두면 유튜브 검색 페이지를 읽어서 관련 뉴스 영상을 찾고, 넣으면 YouTube Data API로 더 안정적으로 찾아요 (Google Cloud 콘솔에서 무료 발급, 하루 약 100회 검색).
- `AISSTREAM_API_KEY` : https://aisstream.io 에서 GitHub로 로그인하면 무료로 받아요. 넣으면 선박 레이어가 켜져요 (Node 22 이상).
- `ANTHROPIC_API_KEY` : https://console.anthropic.com 에서 발급. 넣으면 "상황 브리핑" 탭의 **Claude 분석 요청** 버튼이 켜져요. 누를 때마다 요금이 나가요 (30초에 1회 제한).

### 유튜브 라이브 카메라 등록 (cams.json)

자주 보는 라이브캠이 있으면 `cams.json`에 넣어 두세요. 근처(기본 800km)에서 지진이 나면 팝업에서 자동 재생돼요.

```json
{ "name": "도쿄 시부야", "lat": 35.659, "lng": 139.700, "youtube": "영상ID", "radiusKm": 800 }
```

`youtube`에는 주소 `watch?v=` 뒤의 ID만 넣어요. 라이브 ID는 채널 사정으로 바뀔 수 있어요.

### 검색, 타임라인, 연결 그래프

- **검색** (`/` 키): 나라, 도시, 원전, 해협 이름이나 기사 단어로 찾아요. 장소를 고르면 그 지역 사건과 연결 그래프, **이 지역 Claude 브리핑** 버튼이 뜨는 지역 카드가 열려요.
- **타임라인**: 아래 막대 위를 끌면 그 구간의 사건만 보여요. **▶ 재생**을 누르면 지난 7일을 40초 동안 되감아 보여 줘요. **● 실시간**을 누르면 지금으로 돌아와요.
- **연결 그래프**: 사건 카드마다 주변 사건, 원전, 해상 요충지, 도시를 거리와 함께 그려 줘요. 점을 누르면 그쪽으로 넘어가요.
- **Claude 브리핑**: 사건 카드에서는 그 사건에 묶인 자료만, 지역 카드에서는 그 지역 자료만 근거로 분석해요.

### 분석 화면 (지도 · 그래프 · 표)

화면 위쪽 **지도 / 그래프 / 표** 버튼(M · G · T 키)으로 같은 자료를 다른 모양으로 봐요. 세 화면은 필터와 선택을 함께 써요.

- **분포 탭**: 왼쪽 패널의 분포 탭에서 유형, 나라, 출처, 심각도별 건수를 막대로 봐요. 막대를 누르면 그 값으로 걸러지고, 지도·그래프·표·타임라인이 함께 좁혀져요. 걸린 필터는 피드 위에 칩으로 보이고 ×로 풀어요.
- **선택**: 피드에서 Shift+클릭하면 사건을 여러 개 고를 수 있어요. 고른 사건은 지도에서 밝게, 나머지는 흐리게 보여요.
- **검색 확장 (Search Around)**: 사건 카드 아래 버튼으로 같은 출처, 같은 나라, 반경 안의 사건, 근처 원전·해협을 한 번에 연결해요. 연결은 지도 위 선과 그래프에 같이 나타나요.
- **그래프**: 사건, 나라, 출처를 점으로, 관계를 선으로 그려요. 점을 누르면 사건 카드가 열려요.
- **표**: 걸러진 사건을 열 머리를 눌러 정렬해 볼 수 있어요.

### 평면 지도 (D)

위쪽 **평면** 버튼(D 키)은 같은 자료를 평평한 세계 지도로 보여 줘요. 끌어서 이동하고 휠이나 +/−로 확대해요.

- **영역 선택**: 켠 뒤 지도 위에 손으로 영역을 그리면 그 안의 사건이 선택돼요. Shift를 누른 채 그리면 기존 선택에 더해요.
- **히트맵**: 기사와 신호가 몰린 곳을 열 지도로 보여 줘요.
- **태풍 경로 재생**: 아래 타임라인의 ▶ 재생이나 구간 선택을 따라 태풍 경로가 그 시각까지 그려져요.
- 내 객체, 가져온 윤곽선, 연결선도 함께 보여요.

### 그래프 배치

그래프 위쪽에서 배치 방식을 골라요: 자동, 동심원(심각도 높은 사건이 가운데), 계층, 원형, 격자, 시간순(가로는 시간, 줄은 사건 유형). **나라 숨김 / 출처 숨김**으로 노드를 줄일 수 있어요. 노드를 끌어 놓으면 **직접 배치**로 바뀌고, 그 배치는 조사에 함께 저장돼요. **PNG**로 그래프 이미지를 받을 수 있어요.

### 조사 저장 · 공유

왼쪽 패널의 **조사** 탭에서 지금 보고 있는 분석을 통째로 저장해요. 필터, 고른 사건, 검색 확장으로 만든 연결, 보고 있던 화면(지도·그래프·표, 전용 화면), 기간, 카메라 위치, 메모가 함께 들어가요.

- **저장**: 이 브라우저에만 저장돼요. 서버에는 아무것도 올라가지 않아요.
- **공유 링크 복사**: 조사 내용을 주소 안에 압축해 넣은 링크를 만들어요. 받는 사람이 열면 같은 화면이 떠요.
- **파일로 내보내기 / 파일에서 불러오기**: `.json` 파일로 보관하거나 넘길 수 있어요.
- 조사에 쓴 사건은 사본도 같이 저장돼서, 그 사건이 실시간 목록에서 빠진 뒤에도 다시 열 수 있어요.
- **작업 기록**: 저장, 열기, 공유, 삭제를 이 브라우저 안에 기록해 둬요.
- 브라우저 데이터를 지우면 저장한 조사도 사라지니, 중요한 건 파일로 내보내 두세요.

### 내 객체 · 연결 · 메모 · 합치기

- **지구본에 객체 추가** (조사 탭): 누른 뒤 지구본을 찍으면 그 자리에 장소, 시설, 관심 지역, 메모 지점을 만들어요. 이름과 메모를 붙일 수 있어요. 사람은 객체로 만들 수 없어요.
- **내가 만든 연결**: 사건 카드나 객체 카드에서 다른 사건·객체를 고르고 관계(원인, 같은 지역 등)를 적어 연결해요. 지도에는 주황 선, 그래프에는 주황 선으로 보여요.
- **내 메모**: 사건 카드마다 메모를 남길 수 있어요. 보고서에도 들어가요.
- **같은 사건 합치기**: 따로 잡힌 보도가 같은 일이면 사건 카드에서 합쳐요. 합친 쪽은 목록에서 사라지고 신호가 한 사건으로 모여요. **분리**로 되돌릴 수 있어요.
- 이 모든 건 조사에 담겨서, 조사를 저장하거나 공유하면 같이 가요.

### 파일 가져오기 (CSV · GeoJSON · KML)

조사 탭의 **CSV · GeoJSON · KML 가져오기**로 위치 목록을 내 객체로 불러와요.

- **CSV**: 머리글에 `lat`/`lng` (또는 `위도`/`경도`) 열이 있어야 해요. `name`(이름), `description`(메모), `type`(종류) 열은 있으면 써요. 쉼표나 탭으로 나뉜 파일 모두 돼요.
- **GeoJSON / KML**: 점은 점으로, 선과 영역은 윤곽선을 지구본에 그리고 가운데에 점을 찍어요.
- 한 번에 2,000개, 15MB까지 가져와요. 파일별로 한꺼번에 지울 수 있어요.
- 공개된 장소와 시설만 다뤄요. 사람의 위치 기록은 가져오지 마세요.

### 보고서와 알림

- **보고서 만들기** (조사 탭): 고른 사건(없으면 지금 걸러진 사건 30건)으로 인쇄용 보고서를 새 탭에 열어요. 제목, 메모, 지구본 화면, 사건별 신호와 원문 링크, 연결 목록이 들어가요. **인쇄 · PDF로 저장**을 누르면 PDF로 받을 수 있어요.
- **저장한 검색 알림** (조사 탭 아래): 지금 걸린 필터에 단어와 최소 심각도를 더해 규칙으로 저장해요. 맞는 사건이 새로 생기거나 심각도가 오르면 화면 위에 알림이 뜨고, 소리가 켜져 있으면 울려요. 브라우저 알림을 허용하면 다른 탭을 보고 있을 때도 알려 줘요. 페이지가 열려 있을 때만 동작해요.

### 유형별 전용 화면

위쪽 **지진 / 재난·태풍 / 항공 / 뉴스·분쟁** 버튼(Shift+1~4)을 누르면 지구본은 그대로 두고 오른쪽에 그 유형 전용 패널이 열려요. 같은 버튼이나 Esc로 닫아요.

- **지진**: 7일 규모-시간 분포, 깊이별 건수, 일본 기상청 최근 발표, 큰 지진 순 목록.
- **재난·태풍**: NASA EONET 종류별 건수, 진행 중인 폭풍·태풍 목록, 지구본 위 태풍 이동 경로(하늘색 선), 보도가 많은 재난.
- **항공**: 지구본 가운데 반경 약 460km 항공기를 20초마다 갱신해요. 고도 분포, 기종 상위, 가까운 비행, 비상 스쿼크(7500 · 7600 · 7700)를 보여요. 지구본을 돌린 뒤 "여기서 다시 찾기"를 누르세요.
- **뉴스·분쟁**: 24시간 시간대별 기사 수, 많이 보도된 곳, 언론사별 건수, 최신 헤드라인.

### 뉴스

뉴스 RSS를 3분마다 가져와서, 기사 제목에 나온 나라나 도시 이름으로 위치를 정해 지구본에 보라색 점으로 찍어요. 제목에 지명이 없는 기사는 건너뛰어요.

- 기사는 사건으로 묶여요. 심각도 3 이상이거나 속보인 사건이 새로 생기거나 커지면 지구본이 그곳으로 날아가요. 지진 경보가 우선이고, 뉴스로 생긴 사건은 2분에 한 번까지만 날아가요.
- 사건 카드의 신호 목록에서 각 기사 원문을 열 수 있어요.
- 위치는 제목의 지명으로 자동 추정한 거라 가끔 틀릴 수 있어요.
- 다른 언론사를 보고 싶으면 `feeds.json`을 만들어 목록을 바꿀 수 있어요.

```json
{ "feeds": [ { "name": "BBC World", "url": "https://feeds.bbci.co.uk/news/world/rss.xml" } ] }
```

## 5. 조작

| 키 | 동작 |
|---|---|
| Space | 새 경보가 와도 자동으로 날아가지 않게 끄기/켜기 |
| N | 심각도 3 이상 사건 순서대로 이동 |
| E | 긴급지진속보 테스트 (가짜 속보로 연출 확인, 위쪽 "도구" 메뉴에도 있어요) |
| J | J-Alert 미사일 데모 ("도구" 메뉴) |
| 1–9 | 레이어: 지진, 분쟁, 재난, 사고, 주요 뉴스, 원전, 해상 요충지, 항공기, 위성 (선박·항로·낮/밤은 클릭) |
| M · D · G · T | 지도 · 평면 지도 · 그래프 · 표 화면 |
| Shift+1~4 | 전용 화면: 지진, 재난·태풍, 항공, 뉴스·분쟁 |
| / | 검색 |
| Esc | 정보 창 닫기, 지도로 돌아가기, 전용 화면 닫기 |

지구본의 지진 점, 피드 항목, 하단 타임라인 막대를 누르면 그 지진으로 이동해요.

## 6. 알아 두세요

- 진도 추정, 지진파 도달 시간, 쓰나미 도달 시간은 공식 값이 아니라 공식을 이용한 대략치예요. 실제 대피 판단은 반드시 기상청·재난문자 같은 공식 경보를 따르세요.
- 긴급지진속보는 P2P지진정보가 기상청 발표를 중계한 것이라 몇 초 늦을 수 있어요.
- 항공기 데이터는 airplanes.live·adsb.fi·adsb.lol 자원봉사 수신망 기준이라 지역에 따라 비어 있을 수 있어요.
- PC에서 실행하면 서버는 내 PC(127.0.0.1)에서만 열려요. 다른 기기에서도 보려면 아래 "사이트로 올리기"를 쓰세요.

## 7. 문제 해결

- **"포트 3117을 이미 쓰고 있어요"** : 이미 켜져 있는 창이 있는지 확인하거나 `.env`에서 `PORT=3118`처럼 바꾸세요.
- **화면에 지진이 안 나와요** : 상단 USGS 점이 빨간색이면 인터넷 연결이나 방화벽을 확인하세요. 연결이 안 되면 저장된 기록으로 대신 보여줘요.
- **AI 버튼이 회색이에요** : `.env`에 `ANTHROPIC_API_KEY`가 있는지, 서버를 다시 켰는지 확인하세요.

## 8. 사이트로 올리기 (Render 무료)

1. 이 폴더를 GitHub 저장소에 올려요.
2. https://render.com 에 GitHub로 가입하고 **New → Blueprint**에서 그 저장소를 골라요. `render.yaml`을 읽어서 알아서 설정돼요.
3. 키를 묻는 칸이 나오면 필요한 것만 넣어요. 비워 둬도 돼요.
   - `WINDY_API_KEY` : 웹캠 영상
   - `YOUTUBE_API_KEY` : 뉴스 영상 (선택)
   - `ANTHROPIC_API_KEY` + `ADMIN_PASSWORD` : Claude 분석. 사이트에서는 **비밀번호를 같이 넣어야만** 켜져요 (남이 눌러 요금이 나가는 걸 막으려고요).
4. 배포가 끝나면 `https://watchfloor-xxxx.onrender.com` 주소가 생겨요.

무료 요금제는 15분쯤 아무도 안 들어오면 잠들어서, 다음에 열 때 30초~1분 걸려요. 사이트 모드에서는 "속보 테스트"가 내 화면에서만 재생되고 다른 사람 화면에는 안 떠요.

## 뉴스 영상 팝업

뉴스에서 나온 사건을 열면 웹캠 대신 **관련 뉴스 영상** 팝업이 떠요. 기사 제목으로 최근 1주일 안에 올라온 유튜브 영상을 찾아 소리 끈 채로 재생하고, 아래 버튼으로 다른 영상(최대 5개)을 고를 수 있어요. 영상이 없거나 퍼가기가 막힌 영상이면 "유튜브에서 더 보기"나 "기사 원문"을 누르세요. × 로 닫아요.

## 휴대폰에서 쓰기

폭이 좁은 화면에서는 왼쪽 패널이 **아래에서 올라오는 시트**가 돼요. 맨 위 손잡이를 누르면 접힘 → 반쯤 → 크게 순서로 바뀌고, 위아래로 끌어도 돼요. 접힌 상태에서 탭(피드·분포·조사·브리핑)을 누르면 다시 열려요. 크게 펼친 채로 사건을 누르면 지도가 보이도록 반쯤으로 내려가요.

## 폴더 구성

```
server.js          실시간 데이터 수집 + 화면 제공
news.js            뉴스 RSS 수집 + 지명으로 위치 추정
events.js          신호를 사건으로 묶는 엔진
intel.js           위성, NASA 자연재해, 선박 수집
public/            화면 (index.html, 지도 데이터, globe.gl)
data/snapshot.json 오프라인/데모용 지진 기록
cams.json          내가 등록하는 유튜브 라이브캠
.env.example       선택 기능 키 예시
render.yaml        Render 사이트 배포 설정
```

globe.gl, satellite.js (둘 다 MIT 라이선스) 를 `public/vendor/`에 포함하고 있어요.
